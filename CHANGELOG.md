# Changelog

## 0.1.0

- First release: a hex editor that works the way HxD works.
- Files of any size (a piece table over the file on disk), Insert / Overwrite, Undo / Redo, safe saving.
- Data inspector (editable), Find / Replace (hex, text, numbers), Go To, Select Block, Fill, Copy As.
- Bookmarks, Checksums (CRC-32, MD5, SHA-1, SHA-256, SHA-512), File compare.
- Disks and disk images, read-only until you allow writing; only changed sectors are written.
- "Edit with PR7-HX" in Explorer's menu; OBSIDIAN and AURORA finishes; Check for Updates.
